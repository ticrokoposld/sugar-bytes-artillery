## Overview

Sugar Bytes Artillery is an effects processor combining filters, distortion, delay, reverb, and modulation in a freely routeable signal chain for adventurous sound design.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sugar Bytes Artillery** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **12 Effect Modules** | Filter, overdrive, delay, reverb, chorus, phaser, and more modules |
| **Free Routing** | Drag-and-drop signal flow between any modules in any order |
| **Modulation** | LFOs and envelopes modulate any effect parameter in the chain |
| **Preset Library** | Hundreds of factory presets demonstrating complex effect combinations |
